# VSC Platform V3 — Athlete Timeline Specification (ATHLETE_TIMELINE_V3)
Version: 1.0 (Official Standard)

This document specifies the design, event triggers, schemas, and indexing strategies for the **Athlete Timeline** within the Vietnam Slingshot Championship (VSC) Platform V3. 

Rather than duplicating transactional details across multiple documents, the Athlete Timeline compiles chronological entries inside `/athlete_timeline_events`, creating a chronological narrative of an athlete's career.

---

## 1. Timeline Architectural Philosophy

*   **Immutable Append-Only Ledger**: Once a timeline event is created, it is never modified. Corrections are handled by publishing corrective offset events (e.g., event deletions are recorded as cancellation events).
*   **Event-Driven Creation**: The timeline is updated automatically by system triggers generated by business engine operations. It is never edited directly by end-users.
*   **Zero Computation Cost**: Rendering an athlete's timeline requires a simple range query on `/athlete_timeline_events` ordered by `timestamp` desc, eliminating complex multi-collection join operations at load-time.

---

## 2. Event Types & Triggers Matrix

| Event Type | System Trigger | Description | Included Metadata |
| :--- | :--- | :--- | :--- |
| `JOIN_VSC` | Athlete Profile Creation | Athlete first registered on the platform. | `joinedDate`, `province`, `vscNumber` |
| `CLUB_TRANSFER` | Admin/System updates `currentClubId` | Athlete changes representation from Club A to Club B. | `oldClubId`, `newClubId`, `transferDate` |
| `TOURNAMENT_FINISH` | Tournament results finalized | Tournament finishes and score summaries are locked. | `tournamentId`, `rank`, `score`, `competitionMode` |
| `RECORD_BREAK` | Score Engine identifies national record | Athlete achieves a score surpassing previous state/national records. | `recordValue`, `distanceId`, `previousRecord` |
| `PODIUM_FINISH` | Score Engine registers Top 3 | Athlete receives Gold, Silver, or Bronze medals in an official tournament. | `rank`, `medalType`, `competitionMode` |
| `ACHIEVEMENT_UNLOCKED` | Achievement Engine applies badge | Performance statistics trigger milestone badges. | `achievementId`, `badgeName`, `metricValue` |

## 3. Data Schema (`/athlete_timeline_events`)

```json
{
  "eventId": "evt_timeline_990124_003",
  "athleteId": "ath_990124",
  "seasonId": "season_2025",
  "timestamp": "2025-06-15T18:30:00Z",
  "eventType": "TOURNAMENT_FINISH",
  "title": "HCV Cá nhân Giải Slingshot Quốc Gia 2025",
  "description": "Nguyễn Văn A xuất sắc giành Huy chương Vàng nội dung Cá nhân, đạt điểm số tối đa ở khoảng cách 10m.",
  "metadata": {
    "tournamentId": "tour_national_2025",
    "competitionMode": "individual",
    "rank": 1,
    "score": 98,
    "clubId": "club_hanoi",
    "award": "gold_medal"
  }
}
```

### 3.1 Schema Descriptions

*   **`eventId`**: Unique event key composed of `${athleteId}_${timestamp_ms}_${randomSuffix}`.
*   **`athleteId`**: Target athlete identifier. Supports a Firestore single-field index.
*   **`seasonId`**: Optional identifier mapping the timeline event to a specific VSC competitive season.
*   **`eventType`**: Categorized string used by client renderers to select appropriate icons, color treatments, and detail overlays.
*   **`metadata`**: Variable mapping object containing domain-specific metrics tailored to the specific event context.

---

## 4. Query & Presentation Standards

1.  **Chronological Range Queries**:
    ```javascript
    const q = query(
      collection(db, "athlete_timeline_events"),
      where("athleteId", "==", athleteId),
      orderBy("timestamp", "desc")
    );
    ```
2.  **Lazy Loading**:
    Clients must paginate timeline rendering in increments of 10-15 events. This prevents performance degradation for athletes with long competitive histories spanning multiple years.
3.  **UI Representation (Theme Compatibility)**:
    Events are rendered inside a vertical timeline track. Icons are drawn using standard `lucide-react` definitions depending on `eventType`:
    *   `JOIN_VSC`: `UserPlus` (Emerald badge)
    *   `CLUB_TRANSFER`: `ArrowLeftRight` (Indigo badge)
    *   `TOURNAMENT_FINISH`: `Trophy` (Golden yellow badge)
    *   `RECORD_BREAK`: `Zap` (Rose red badge)
    *   `ACHIEVEMENT_UNLOCKED`: `Award` (Cyan badge)
